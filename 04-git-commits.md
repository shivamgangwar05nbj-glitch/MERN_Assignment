# **Assignment 4 – Repository with at least Three Meaningful Commits**

**Objective:** Create a GitHub repository and upload your project with at least three meaningful commits.

### **Step 1: Create a GitHub Repository**

1. Open [GitHub](https://github.com?utm_source=chatgpt.com).
2. Login to your account.
3. Click the **+** icon → New Repository.
4. Enter repository name: `Assignment-4`.
5. Select Public.
6. Click **Create Repository**.

### **Step 2: Create Project Files**

Create these three files in VS Code:

- `index.html`
- `style.css`
- `README.md`

Example `index.html`:

```
<!DOCTYPE html>
<html>
<head>
    <title>My First Project</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Welcome to My Website</h1>
    <p>This is my first GitHub project.</p>
</body>
</html>
```

### **Step 3: Make Three Meaningful Commits**

A commit means saving your project changes with a message.

| Commit | Changes          | Commit Message            |
| ------ | ---------------- | ------------------------- |
| 1      | Create HTML file | Initial HTML structure    |
| 2      | Add CSS styling  | Add CSS styling           |
| 3      | Update README    | Add project documentation |

### **Step 4: Upload Using VS Code Terminal**

Open the terminal in VS Code and run:

```
git init
git add .
git commit -m "Initial HTML structure"
```

After making CSS changes:

```
git add .
git commit -m "Add CSS styling"
```

After updating README:

```
git add .
git commit -m "Add project documentation"
```

Connect your GitHub repository:

```
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

### **Step 5: Verify Your Assignment**

Open your GitHub repository and check:

- Repository is created.
- Project files are uploaded.
- At least 3 meaningful commits are visible.
- Commit messages are meaningful.
