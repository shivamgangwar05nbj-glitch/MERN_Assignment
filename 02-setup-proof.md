[digipedia.tudelft.nl](https://digipedia.tudelft.nl/tutorial/html-and-css-basics/?utm_source=chatgpt.com)

**Steps:**

1. Open Visual Studio Code.
2. Click on the Extensions icon.
3. Search for **Live Server**.
4. Install the Live Server extension by Ritwick Dey.
5. Create a new file named `index.html`.
6. Write the following HTML code:

```
<!DOCTYPE html>
<html>
<head>
    <title>My First Webpage</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>My Live Server is working.</p>
</body>
</html>
```

7. Right-click on the HTML file.
8. Select **Open with Live Server**.
9. The webpage will open automatically in your browser.
10. Take a screenshot of the running webpage.
